# Sneha Kaushal — Portfolio Website

A modern, premium, fully responsive personal portfolio built with React.js + Tailwind CSS + Framer Motion.

## 🚀 Features

- **Dark futuristic aesthetic** with neon blue, purple, and cyan accents
- **Glassmorphism** card design
- **Animated particles** background (canvas-based)
- **Typing animation** for roles
- **Scroll progress bar** at the top
- **Custom animated cursor** (dot + ring)
- **Loading screen** with progress bar
- **Dark/Light mode toggle**
- **Back to top button**
- **Smooth scroll** between sections
- **Framer Motion** animations with scroll reveal
- **Fully responsive** — mobile, tablet, desktop
